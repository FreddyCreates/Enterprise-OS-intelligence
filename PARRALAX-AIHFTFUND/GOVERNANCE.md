# GOVERNANCE

## Purpose

Governance preserves bounded control over:

- agents
- strategies
- protocols
- treasury movement
- token issuance
- live execution upgrades

## Governance rule

No asset issuance, authority expansion, treasury movement, or live execution upgrade should occur without a governance record.

## Governance objects

- agent mandates
- strategy approvals
- treasury authorizations
- protocol changes
- asset issuance approvals
- emergency overrides

## Governance holders

- founder/operator authority
- internal governance mechanisms
- multisig / approval groups
- future structured governance rails
